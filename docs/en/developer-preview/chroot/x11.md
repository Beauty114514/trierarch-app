# chroot + X11

English | [中文](../../../zh-CN/developer-preview/chroot/x11.md)

This profile runs an X11 desktop inside a chroot rootfs. The host provides the X11 surface; the guest needs an installed X11 session.

## Create and edit the profile

```sh
trierarch --create arch-chroot-x11
trierarch --config arch-chroot-x11
trierarch --status arch-chroot-x11
```

Set `runtime = "chroot"`, the absolute `rootfs`, `display.type = "x11"`, `launch.argv`, and `graphics.renderer`. The complete sample is
[`x11.profile.toml`](x11.profile.toml); change the
container/rootfs/user values to match your device.

Start the profile and select the X11 surface in Trierarch. chroot requires a working `su` provider. GPU renderer support depends on the device and the guest drivers; start with llvmpipe when validating the session.

Profile sample: [`x11.profile.toml`](x11.profile.toml)
