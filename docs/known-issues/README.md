## Early-version notes

The Firefox and Baloo entries are consolidated from the earlier
`trierarch-optimize` notes. They were written for early PRoot/rootfs setups and
remain useful when an older distribution or rootfs shows the same behavior.
They are workarounds, not requirements for every current setup.

Firefox 和 Baloo 两条来自早期的 `trierarch-optimize` 笔记，针对早期
PRoot/rootfs 环境；在旧发行版或旧 rootfs 上仍有参考价值，不代表所有当前环境
都必须这样配置。
