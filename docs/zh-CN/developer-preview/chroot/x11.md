# chroot + X11

[English](../../../en/developer-preview/chroot/x11.md) | 中文

这个 profile 在 chroot rootfs 内运行 X11 桌面。host 提供 X11 surface；guest 需要安装 X11 session。

## 创建和编辑 profile

```sh
trierarch --create arch-chroot-x11
trierarch --config arch-chroot-x11
trierarch --status arch-chroot-x11
```

填写 `runtime = "chroot"`、rootfs 绝对路径、`display.type = "x11"`、`launch.argv` 和 `graphics.renderer`。完整样例见
[`x11.profile.toml`](x11.profile.toml)；把
container/rootfs/user 换成设备上的实际值。

启动 profile 后在 Trierarch 中选择 X11 surface。chroot 需要可用的 `su`。GPU renderer 取决于设备和 guest 驱动；第一次验证建议先用 llvmpipe。

Profile 样例: [`x11.profile.toml`](x11.profile.toml)
